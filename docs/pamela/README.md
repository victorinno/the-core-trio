# Materiais de Pamela

Esta coleção reúne o card-fonte de Pamela e os documentos criados para orientar a expansão da rota no date sim. O card-fonte é preservado como referência de personagem; o planejamento e a revisão devem ser consultados antes de escrever ou implementar novas cenas.

| Arquivo | Uso previsto |
|---|---|
| `scenario-I-EUWsXiRFr8-story-cards-10.json` | Cards originais do cenário, incluindo o card-fonte de Pamela e o contexto do polycule. |
| `PAMELA_ROUTE_1H_PLAN.md` | Planejamento mecânico e narrativo de uma rota de pelo menos uma hora. |
| `PAMELA_CARD_ALIGNMENT_REVIEW.md` | Comparação entre o card-fonte e o planejamento anterior, com correções de caracterização. |

> **Diretriz de escrita:** para Pamela, priorize gentileza, curiosidade, distração espontânea, lealdade à Jessica e atração consentida pela pessoa jogadora. Não a trate como organizadora exausta da casa ou como recompensa romântica comprável.
