## Ordem de leitura

1. Abra este índice e confirme a versão ativa.
2. Leia o conjunto-fonte de cards quando a tarefa envolver voz, relação com Jessica, lealdade ou motivação de Pamela.
3. Leia o GDD canônico para cenas, atributos, economia, gates e critérios de implementação.
4. Leia o mapa para decidir em que local uma nova ação ou transição deve ocorrer.
5. Consulte a matriz de sistemas para garantir que trabalho, carteiras, loja, inventário, dates e Crescent Market não sejam usados como atalhos afetivos.
6. Consulte o relatório de QA antes de uma alteração no motor de rotinas, nos atalhos, no mapa ou na rota Pamela.

> **Regra de conflito:** o card-fonte define quem Pamela é. O GDD canônico define como essa personagem funciona no jogo. O mapa define onde os sistemas acontecem. Documentos em `archive/` existem apenas para contexto histórico.
